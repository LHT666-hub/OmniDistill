# Project-retro mode

Reconstruct the project from artifacts, not from the final README alone.

Inspect:

- requirements and acceptance criteria;
- architecture and decision records;
- commit and issue history;
- incidents, rejected approaches, and rollbacks;
- dependency and environment constraints;
- tests and deployment behavior;
- current reproduction path.

Extract:

- invariant decisions that future rebuilds must preserve;
- replaceable implementation choices;
- failure signatures and recovery actions;
- a minimal reproduction workflow;
- open risks and technical debt.

Do not expose secrets, internal URLs, credentials, personal data, or proprietary source in a redistributable package.
