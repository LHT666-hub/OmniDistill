# Person-thinking mode

## Collection lanes

Collect separately:

1. books and long-form first-person writing;
2. long interviews, talks, and question-and-answer sessions;
3. short public expression;
4. consequential decisions and actions;
5. credible criticism and external assessment;
6. chronology and documented changes of view.

Do not let one lane substitute for all others.

## Extraction tests

A proposed mental model should pass:

- **recurrence:** appears independently more than once;
- **generativity:** changes how a new case is analyzed;
- **distinctiveness:** is more specific than generic good advice;
- **behavioral alignment:** is not contradicted by salient decisions without explanation;
- **temporal scope:** states when the model was observed.

Put failed candidates in notes, not core rules.

## Identity boundary

Default to third-person framing: “This Skill applies a documented decision pattern associated with X.” Do not write “I am X.” Voice and rhetorical traits belong in an optional persona module and must never substitute for evidence.
