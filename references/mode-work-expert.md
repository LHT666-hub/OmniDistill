# Work-expert mode

Separate four kinds of observations:

| Kind | Meaning | Default destination |
|---|---|---|
| transferable capability | Works across comparable environments | Core Skill |
| contextual rule | Depends on organization, role, or tool | Scoped reference |
| personal preference | Useful but not necessary for performance | Optional preference |
| persona trait | Tone, manner, social posture | Optional persona module |

## Minimum extraction

- task triggers and definitions of done;
- inputs, tools, templates, and outputs;
- pre-flight checks;
- decision rights and escalation points;
- normal workflow and exception branches;
- common failure signatures and recovery;
- handoff and communication protocol;
- tacit constraints absent from formal SOPs.

Use artifacts and observed decisions to validate interview claims. Do not redistribute internal records in the generated Skill.
