# Corpus mode

Build two separate products:

1. a navigable knowledge map that answers “where is relevant material?”;
2. a capability layer that answers “how should a task be judged or performed?”

## Knowledge map

- assign stable document IDs;
- create a small top-level taxonomy;
- allow a document to be referenced by more than one concept when needed;
- retain source links and dates;
- record contradictions and obsolete material;
- use progressive loading rather than a single giant summary.

## Capability threshold

Frequency is not enough. Promote a corpus pattern into a heuristic only when it has:

- repeated support across independent documents;
- a clear condition and action;
- a plausible reason or mechanism;
- declared scope and counterexamples;
- value on a task not directly answered by the corpus.
